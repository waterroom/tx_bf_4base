# Vivado 工程导入脚本（tcl）提示词模板

> 用法：把下面【提示词】整段复制给 AI（或其他开发环境），替换 `<项目名>`、`<路径>`、`<文件清单>` 即可。参考实现：`C:/workbuddy_chat/tx_bf_4base/scripts/import_tx_bf_4base.tcl`

## 提示词

```
仿照 D:/prj/z690/time_sync/tcl/import_bd_422_pps_time_rec.tcl 的风格，
为 <项目名> 写一个 Vivado 导入脚本 <import_项目名.tcl>，用于在目标工程
Tcl Console 里 source 后一键添加所需源文件、IP 和 TB。

功能（必须幂等，可重复执行）：
1. 删除工程内旧的 <项目名> 源文件（按文件名通配匹配，防重复）
2. 删除旧 TB（仅仿真文件）
3. 删除旧 IP（列出 IP 名）
4. 重新导入 rtl/*.sv —— 用 add_files -norecurse -force -copy_to
   <import_dir>（复制进工程 srcs/imports/<项目名>/，.xpr 记录工程内路径，
   工程移动/原目录删除不受影响）
5. 重新导入 TB —— 同样 -copy_to，并 set_property USED_IN_SYNTHESIS false
6. 重新导入 IP —— 复制 .xci 进工程，逐个 generate_target

硬性要求：
- 幂等：每次先删旧（get_files 匹配）+ 再导入，重复 source 不报错
- 编码：tcl 文件用 GBK 编码（Windows Vivado Tcl Console 用 ANSI 解析，
  UTF-8 中文注释会乱码）
- IP 器件不匹配：目标工程 part 与 IP 定制 part 不同会报
  "IP is locked"，需在 generate 前用 upgrade_ip（先判断 IS_LOCKED）
- generate_target 范围必须收窄：只对本次导入的 IP 名逐个处理
  （用 file tail [file dirname $xci] 取 IP 名再 get_ips -all $ipn），
  禁止用 get_ips 全量 —— 会误生成 BD 内嵌套 IP 报错
  "Nested sub-design ... can only be generated by its parent"
- 结尾打印导入摘要（源/TB/IP 数量 + 使用提示）

文件清单：
- 源文件：<列出 rtl 文件>
- TB：<列出 tb 文件>
- IP：<列出 IP 名 + 源 xci 路径>
```

## 关键坑位速查（写 tcl 时必查）

| 坑 | 处理 |
|----|------|
| 中文乱码 | tcl **GBK** 编码（UTF-8 在 Vivado Tcl Console 乱码）|
| IP locked（器件不匹配）| `if {[get_property IS_LOCKED $ip]} { upgrade_ip $ip }` 再 generate |
| generate 误伤 BD 内 IP | 按 IP 名逐个 `get_ips -all $ipn`，**不用** `get_ips` 全量 |
| 幂等重复 | 先 `get_files -quiet` 匹配删除，再导入 |
| 复制进工程 | `add_files -copy_to <import_dir>`（工程移动不依赖原路径）|
| TB 参与综合 | `set_property USED_IN_SYNTHESIS false [get_files *tb*.sv]` |
| 工程路径 | `[get_property DIRECTORY [current_project]]` + `${proj_name}.srcs/sources_1/imports/` |
